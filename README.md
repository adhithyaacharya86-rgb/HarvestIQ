# HarvestIQ
An automated greenhouse farming and post-harvest technology system.

## Key Features
* **Automated Smart Irrigation:** Real-time water management using soil moisture and humidity sensors.
* **Decay Detection:** RGB sensors and real-time machine learning predictions for crop monitoring.
* **Environmental Control:** Automated temperature control misting for optimal greenhouse conditions.

## Repository Structure
* `/src` - Software source code, data analysis, and machine learning models.
* `/hardware` - Microcontroller code and sensor integration.
* `/media` - Prototype photos and project presentation materials.
